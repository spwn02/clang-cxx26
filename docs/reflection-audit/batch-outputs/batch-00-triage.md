The batch separates into three clusters. Namespace redeclaration/equality issues (#175-176) are addressed by canonicalization and redeclaration-chain work already present in this fork. Reflection NTTP handling is mixed: Itanium mangling is fixed, but Microsoft mangling still has the original unreachable path (#120), while #177 reflects a semantic distinction between an enumerator declaration and an enumerated value. Expansion statements remain the main open-risk area: control-flow validation (#146), destructor splice parsing (#150), non-copyable ranges (#181), and optimized `continue` code generation (#182) lack complete coverage.
